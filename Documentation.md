* Q1: Qu'est-ce que la méthode Agile ?

  Réponse:

  C'est une approche de gstion de projet qui privilégie le developpement progressive, la collaboration, l'adaptaion au changement et les retours reguliers.

* Q2: Quelle sont les piliers de la méthode Agile ?

  Réponse:

  La methode Agile se repose sur quatre valeurs fondamentales:
   
   + Les individus et leurs interactions plutôt que les processus et les outils.
   
   + Un logiciel fonctionnel plutôt qu'une documentation exhaustive.

   + La collaboration avec le client plutôt que la negociation contractuelle.

   + L'adaptation au changement plutôt que le suivi strict d'un plan.
* Q3:  Qu'est-ce que Scrum ?
   
  Réponse:

   Scrum est un cadre de travail Agile qui permet aux équipes de développer des produits complexes de manière itérative et incrémentale.

   Le travail est organisé en périodes courtes appelées Sprints, généralement d'une durée d'une à quatre semaines. Chaque Sprint doit produire un incrément du produit utilisable et répondant aux critères de qualité définis.

* Q4: Quels sont les rôles dans Scrum ?

  Réponse:

  Scrum définit trois responsabilités principales :

   1. Product Owner

   Il maximise la valeur du produit, clarifie les besoins et ordonne les éléments du Product Backlog.

   Dans le projet Élan Fitness, il valide les priorités fonctionnelles, comme la création des pages et les besoins des visiteurs.

   2. Scrum Master

   Il aide l'équipe à comprendre et appliquer Scrum, facilite son fonctionnement et contribue à éliminer les obstacles.

   3. Developers

   Ils réalisent le travail nécessaire à la création de l'incrément du produit.

   Dans ce projet, les membres de l'équipe peuvent prendre en charge la conception, le développement, l'intégration, les tests et l'optimisation du site.

   Ces responsabilités ne correspondent pas nécessairement à trois personnes différentes : une même personne peut assumer plusieurs activités selon l'organisation de l'équipe.

* Q5: Quels sont les événements Scrum ?

  Réponse :

  Scrum comprend cinq événements essentiels, en comptant le Sprint lui-même.

  + Sprint : période durant laquelle l'équipe travaille pour atteindre un objectif.

  + Sprint Planning : réunion de planification du Sprint.

  + Daily Scrum : événement quotidien permettant aux Developers d'inspecter la progression vers l'objectif du Sprint et d'adapter leur plan.

  + Sprint Review : présentation et inspection du résultat avec les parties prenantes afin d'identifier les adaptations utiles.

  + Sprint Retrospective : réunion destinée à améliorer la manière de travailler de l'équipe.

* Q6: Qu'est-ce que le SEO ?
   
  Réponse :

   SEO signifie Search Engine Optimization, ou optimisation pour les moteurs de recherche.

   Il regroupe les techniques permettant d'améliorer la compréhension, l'indexation et la visibilité d'un site dans les résultats de recherche organiques.

* Q7: Comment mesurer les résultats SEO ?
   
  Réponse :

   Les résultats peuvent être suivis à l'aide d'outils comme Google Search Console et Google Analytics, selon les besoins du projet et les paramètres de confidentialité.

   Les indicateurs utiles comprennent :

   + Les impressions dans les résultats de recherche.

   + Les clics provenant des moteurs de recherche.

   + Le taux de clics.

   + Les requêtes qui génèrent des visites.

   + Les pages les plus consultées.

   Les actions importantes, comme l'envoi d'un formulaire.
   
   Il faut analyser ces données dans le temps plutôt que juger les résultats sur une seule journée.

* Q8: Qu'est-ce que l'UX ?

  Réponse :

   UX signifie User Experience, ou expérience utilisateur.

   Elle désigne l'expérience globale d'une personne lorsqu'elle utilise un site web : facilité de navigation, compréhension des informations, rapidité d'exécution des tâches, confiance et satisfaction.

* Q9: Qu'est-ce que l'UI ?

  Réponse :

   UI signifie User Interface, ou interface utilisateur.

   Elle concerne les éléments visuels et interactifs du site : couleurs, typographies, boutons, menus, icônes, images, formulaires et organisation visuelle.

* Q10:  Quels critères permettent d'évaluer la qualité de l'UI ?

  Réponse :

   La qualité de l'interface peut être évaluée à partir de plusieurs critères :

   + Lisibilité des textes.

   + Contraste suffisant entre le texte et l'arrière-plan.

   + Hiérarchie visuelle claire.

   + Cohérence des couleurs et des composants.

   + Visibilité des actions principales.

   + Adaptation aux appareils mobiles.

   + Accessibilité des éléments interactifs.

   Il est également important de ne pas utiliser uniquement la couleur pour transmettre une information.

* Q11: Comment transformer le site One Page en site multipage ?

  Réponse :

   Il faut répartir les sections existantes dans des pages distinctes, créer les fichiers ou les routes nécessaires et mettre en place une navigation commune.

   Selon les technologies utilisées, le site peut être construit avec HTML, CSS et JavaScript, ou avec un framework adapté.

   Une structure simple pourrait être :

   + index.html : page Accueil.

   + programmes.html : page Programmes.

   + a propos.html : page À propos.

   + contact.html : page Contactez-nous.

   + css/style.css : styles communs.

   + js/main.js : interactions et comportements JavaScript.

   + assets/ : logos, photographies et autres ressources.

   Cette structure est un exemple d'organisation pour un site HTML classique et peut être adaptée à la structure technique existante.

* Q12: Qu'est-ce que HTML ?

  Réponse :

   HTML (HyperText Markup Language) est un langage de balisage utilisé pour structurer le contenu d'une page web. Il permet d'organiser les titres, les paragraphes, les images, les liens, les tableaux et les formulaires.

* Q13: Quel est le rôle de HTML dans un site web ?

  Réponse :
   
   HTML définit la structure et le contenu de la page. Par exemple, dans le site Élan Fitness, il permet de créer le menu de navigation, le titre principal, les cartes des programmes sportifs et le formulaire de contact.

* Q14: Qu'est-ce qu'une balise HTML ?

  Réponse :

   Une balise HTML est un élément de syntaxe utilisé pour définir ou délimiter une partie du contenu.
   
   Exemple :

    <p> : balise ouvrante.

     Bienvenue chez Élan Fitness. : contenu.

    </p> : balise fermante.

* Q15: Quelles sont les principales balises de formulaire ?

  Réponse :
   
  Balise	Fonction
  
  <form>	  Regroupe les champs du formulaire

  <label>	  Définit le libellé d'un champ
  
  <input>	  Crée un champ de saisie
  
  <textarea>  Crée une zone de texte multiligne
  
  <select>	  Crée une liste déroulante
  
  <option>	  Définit une option de liste
  
  <button>	  Crée un bouton
  
  <fieldset>  Regroupe des champs liés
  
  <legend>	  Donne un titre à un groupe de champs

  * Q16: Qu'est-ce que CSS ?

    Réponse :

     CSS (Cascading Style Sheets) est un langage de feuilles de style utilisé pour définir l'apparence des éléments HTML : couleurs, polices, dimensions, espacements, alignements et mise en page.
